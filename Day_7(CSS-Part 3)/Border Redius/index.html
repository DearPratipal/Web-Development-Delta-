Border-Radius

Border-radius is a CSS property that allows you to create rounded corners on elements. You can specify the radius for each corner individually or use a single value to apply the same radius to all corners.

Syntax

/* Apply the same radius to all corners */
        border-radius: 10px;
    
/* Apply different radius to each corner */
        border-radius: 10px 20px 30px 40px; /* top-left, top-right, bottom-right, bottom-left */
